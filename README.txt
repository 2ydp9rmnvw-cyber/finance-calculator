理财年化收益计算器（iPhone/iPad 版）

1. index.html 是主程序；已预置 Excel 第一张工作表“理财整理”的有效产品记录。
2. 所有编辑数据保存在当前浏览器的 localStorage 中，不上传服务器。
3. 计算口径：
   - 持有天数 = 计算日期 - 购买日期
   - 估算年化收益率 = (现有金额 - 原始金额) / 原始金额 / 持有天数 * 365
   - 万份收益 = (现有金额 - 原始金额) / 原始金额 * 10000 / 持有天数
4. “计算日期”留空时使用当天日期。
5. iPhone/iPad 安装为桌面 App：
   - 将本文件夹发布到任意 HTTPS 静态网站（GitHub Pages、Cloudflare Pages、Netlify 等）；
   - 用 Safari 打开网址；
   - 点“分享”→“添加到主屏幕”。
6. 可随时用“备份数据”导出 JSON，再用“恢复备份”导入，建议定期备份。

2026-10-08 修复：编辑数字或连续中文时不再因自动刷新导致键盘关闭。升级只需在 GitHub 仓库替换 index.html 和 sw.js；浏览器数据沿用原存储键，不会主动清空。
